# Maze Lab — визуализатор и сравнително изследване на алгоритми за търсене на път

Курсова работа „Разработване и изследване на програмни решения“, ПУ „Паисий Хилендарски“.

## Стартиране
    pip install -r requirements.txt
    python main.py          # интерактивното приложение (pygame)
    python benchmark.py     # експериментите -> results/*.csv и *.png
    python -m pytest -q     # автоматични тестове (12)

## Файлове
- grid.py        – решетка, цени на клетките, запис/зареждане (JSON)
- generators.py  – Backtracker, Prim, Kruskal, случайни препятствия, цикли, кал
- algorithms.py  – BFS, DFS, Dijkstra, A*, Greedy (като генератори -> анимация)
- app.py         – графичен интерфейс; main.py – входна точка
- benchmark.py   – 4 експеримента; test_maze_lab.py – тестове

## Управление
Ляв бутон – рисува (стена/кал) · десен – трие · влачене на старт/цел ·
ИНТЕРВАЛ – старт/пауза · N – стъпка · R – рестарт · G – нов лабиринт ·
C – изчисти · T – състезание на всички алгоритми · 1–5 – алгоритъм ·
S/L – запис/зареждане · +/- – скорост.
